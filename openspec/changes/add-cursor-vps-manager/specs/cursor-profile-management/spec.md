## ADDED Requirements

### 需求:系统必须支持已知关键配置项的表单化编辑
系统必须为已知的关键配置项提供表单化编辑入口，并且必须把未知配置项排除在该表单之外。

#### 场景:编辑已知配置项
- **当** 管理员打开配置页面并编辑系统已知的关键配置项
- **那么** 系统必须允许通过表单提交修改

#### 场景:未知配置项不在表单中
- **当** 某个配置项不属于系统已知字段
- **那么** 系统必须不在表单化配置区域中提供该字段

### 需求:系统必须支持原始配置文件预览后保存
系统必须允许管理员查看和编辑原始配置文件，并且必须在真正保存前展示预览或确认结果。

#### 场景:预览后保存原始配置
- **当** 管理员修改原始配置文件并准备提交
- **那么** 系统必须先展示预览或确认步骤
- **那么** 系统必须在管理员确认后才写入文件

### 需求:系统必须支持管理已有的 user 级 skill
系统必须支持列出、查看、编辑和删除已有的 user 级 skill。编辑必须基于原始文件内容，删除必须要求普通二次确认。

#### 场景:列出和查看 skill
- **当** 管理员进入 skill 管理页面
- **那么** 系统必须列出已有的 user 级 skill
- **那么** 系统必须允许查看 skill 详情或原始内容

#### 场景:编辑 skill
- **当** 管理员修改已有 skill 的原始文件内容
- **那么** 系统必须允许保存更新后的内容

#### 场景:删除 skill
- **当** 管理员请求删除某个已有 skill
- **那么** 系统必须先展示普通二次确认
- **那么** 系统必须仅在确认后执行删除
