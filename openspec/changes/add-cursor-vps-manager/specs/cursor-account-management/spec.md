## ADDED Requirements

### 需求:系统必须使用固定访问令牌保护管理页
系统必须要求用户先通过管理页登录入口提供固定访问令牌，验证通过后才能进入管理界面。生产环境必须要求显式配置该令牌。

#### 场景:令牌有效
- **当** 用户访问管理页并提交有效的访问令牌
- **那么** 系统必须允许用户进入管理界面

#### 场景:令牌无效
- **当** 用户访问管理页并提交无效的访问令牌
- **那么** 系统必须拒绝访问
- **那么** 系统必须向用户显示登录失败信息

### 需求:系统必须支持网页引导式的 Cursor 登录流程
系统必须提供网页引导式的 Cursor 登录流程，并且必须允许用户在外部完成关键认证步骤后回到网页继续确认。

#### 场景:启动登录引导
- **当** 管理员在账号管理界面触发 Cursor 登录
- **那么** 系统必须展示当前步骤和下一步操作提示

#### 场景:外部完成关键步骤
- **当** 用户在外部完成认证要求的关键步骤并返回管理页
- **那么** 系统必须允许用户继续确认当前登录结果

### 需求:系统必须按 best-effort 展示当前 Cursor 用户信息
系统必须在可获取时展示当前 Cursor 账号的已登录状态、邮箱和显示名；当部分字段不可获取时，系统必须仍然展示可确认的最小状态，而不能伪造字段。

#### 场景:可获取邮箱和显示名
- **当** 系统能够从 Cursor 相关状态中解析出邮箱和显示名
- **那么** 系统必须展示已登录状态、邮箱和显示名

#### 场景:只能确认已登录
- **当** 系统只能确认当前已登录，但无法稳定获取邮箱或显示名
- **那么** 系统必须展示已登录状态
- **那么** 系统必须不展示伪造的邮箱或显示名
