## ADDED Requirements

### 需求:仓库必须提供 README 作为项目入口
仓库必须提供 `README.md`，用于说明项目定位、Phase 1 范围、核心技术栈和基本入口。

#### 场景:新读者打开仓库
- **当** 新读者访问仓库根目录
- **那么** 系统必须提供可读的 `README.md`
- **那么** `README.md` 必须说明该项目是面向单用户 VPS 的 Cursor CLI 管理器

### 需求:仓库必须提供结构化项目文档
仓库必须提供项目说明、技术方案、用户已拍板项和文档索引文档，以便将当前讨论结果转化为长期可查阅的说明材料。

#### 场景:查看项目说明
- **当** 读者希望了解项目目标、范围和非目标
- **那么** 系统必须提供独立的项目说明文档

#### 场景:查看技术方案
- **当** 读者希望了解技术架构、模块边界和交付方式
- **那么** 系统必须提供独立的技术方案文档

#### 场景:查看已拍板项
- **当** 读者希望了解已确认的产品和技术决策
- **那么** 系统必须提供独立的已拍板项文档

### 需求:仓库必须提供文档列表和运行部署说明
仓库必须提供文档索引，并且必须提供覆盖本机快启、Compose 验收和基础部署入口的运行部署说明。

#### 场景:查看文档列表
- **当** 读者进入文档目录
- **那么** 系统必须提供一个可导航的文档列表

#### 场景:查看运行部署说明
- **当** 读者希望本机运行或部署系统
- **那么** 系统必须提供覆盖开发态快启和 Compose 验收的说明文档
