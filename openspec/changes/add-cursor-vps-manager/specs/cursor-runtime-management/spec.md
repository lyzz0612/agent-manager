## ADDED Requirements

### 需求:系统必须支持容器内受管的 Cursor 运行时安装
系统必须允许管理员在网页中手动触发 Cursor 安装，并且必须将 Cursor 安装到应用管理的容器内受管目录中。系统必须从官方在线来源安装最新版。

#### 场景:首次成功安装
- **当** 当前受管目录中不存在 Cursor，且管理员在网页中触发安装
- **那么** 系统必须从官方在线来源下载并安装最新版 Cursor 到受管目录
- **那么** 系统必须将安装状态更新为已安装

#### 场景:安装失败
- **当** 管理员触发安装，但官方在线来源不可达或安装命令失败
- **那么** 系统必须向管理员显示失败结果
- **那么** 系统必须不把当前状态误标记为已安装

### 需求:系统必须展示 Cursor 安装状态和当前版本
系统必须在管理界面中展示 Cursor 当前是否已安装，并且在已安装时展示当前版本信息。

#### 场景:未安装状态
- **当** 受管目录中没有可用的 Cursor 安装
- **那么** 系统必须展示未安装状态

#### 场景:已安装状态
- **当** 受管目录中存在可用的 Cursor 安装
- **那么** 系统必须展示已安装状态
- **那么** 系统必须展示当前已安装版本

### 需求:系统必须支持手动触发 Cursor 升级
系统必须允许管理员在网页中手动触发 Cursor 升级，并且升级必须作用于当前受管安装。

#### 场景:成功升级
- **当** 当前已安装 Cursor，且管理员在网页中触发升级
- **那么** 系统必须执行升级流程
- **那么** 系统必须在升级成功后展示新的当前版本

#### 场景:升级失败
- **当** 当前已安装 Cursor，且升级流程失败
- **那么** 系统必须向管理员显示失败结果
- **那么** 系统必须保留可检测的现有安装状态
